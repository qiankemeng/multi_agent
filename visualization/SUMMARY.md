## 🔧 技术架构

### 后端 (Python)

```
visualizer.py
├── AST解析 (ast模块)
├── 文件遍历 (pathlib)
├── 数据结构 (dataclasses)
└── JSON导出 (json)
```

**关键技术**:
- 使用`ast.parse()`解析Python代码
- 无需导入模块，避免副作用
- 支持提取docstring、类型注解、装饰器

### 前端 (Web)

```
template.html
├── D3.js v7 (力导向图)
├── 原生JavaScript (逻辑)
├── CSS3 (样式和动画)
└── Async/Await (数据加载)
```

**设计特点**:
- 无需构建工具，纯HTML单文件
- 响应式设计，支持各种屏幕
- 现代化UI，渐变色和流畅动画
- 离线可用，数据本地加载

## 🐛 已知限制

1. **大型项目性能**: 超过1000个类时，关系图可能较慢
   - 解决方案: 添加分页或过滤功能

2. **跨文件引用**: 目前只分析继承关系
   - 扩展方向: 添加函数调用、导入关系分析

3. **动态代码**: 无法分析运行时动态生成的类
   - 这是静态分析的固有限制
